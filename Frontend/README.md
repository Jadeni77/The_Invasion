Game Features:
* Losing a game will loss materials or cause worker injury.
    * Enermy can sneak into you team at a random chance.
    * Worker injury will refuse to work.
    * Player official ranking will be decrement.
* Player can have official ranking. (High ranking will receive more resources)
    * https://docs.google.com/spreadsheets/d/1Z7RwXW1BkmFzLddi0fun_c5aUq82IcrwTXjP6DRL1EU/edit?gid=0#gid=0 (ranking sheet)
* There can be events to force a fight happening when the player is online.
